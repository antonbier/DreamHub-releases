DreamHub apt feed

This is not a web page: it is the package feed for a Dreambox, read by apt. Nothing to see here.

To use it, on the box (Dreambox One/Two: arm64; DM900/DM920: armhf):

echo "deb [trusted=yes] https://antonbier.github.io/DreamHub-releases/apt/armhf ./" > /etc/apt/sources.list.d/dreamhub.list
apt-get update && apt-get install dreamhub

The feed is not signed, like the other Dreambox plugin feeds: add only this address. More in the README, the packages and release notes are on the releases page.
